# 🏫 CampusResolve 2.0
### Your Campus. Your Voice. Real Resolution.

CampusResolve 2.0 is a modern campus grievance management platform designed to simplify how students report college-related issues and how administrators manage and resolve them.

Our vision is to create a transparent, organized, and scalable system that connects students with the right college departments.

> **TeamAlpha | Hackathon Project**

---

## 🚨 Problem Statement

Students often face difficulties reporting campus issues and tracking their resolution.

Common challenges include:
- Lack of a centralized complaint reporting system.
- Difficulty identifying the appropriate department.
- Limited visibility into complaint progress.
- Inefficient communication between students and administrators.
- Difficulty analyzing recurring campus issues.

## 💡 Our Solution

CampusResolve 2.0 aims to provide a centralized digital platform where students can report grievances and track their status while administrators manage complaints efficiently.

### ✨ Key Features

- 📝 **Complaint Management** — A structured way to report campus issues.
- 📊 **Student Dashboard** — Designed to help students monitor their complaints.
- 🛠️ **Admin Dashboard** — Designed for administrators to manage grievances.
- 🔄 **Complaint Tracking** — Planned status tracking throughout the resolution process.
- 🤖 **AI-Powered Categorization** — Planned automatic classification of complaints.
- 🎯 **Smart Department Routing** — Planned routing of complaints to relevant departments.
- 📈 **Analytics & Insights** — Planned reporting to identify recurring campus issues.
- 🌐 **Scalable Architecture** — A vision for supporting multiple colleges in the future.

*Note: Features described as planned are part of the roadmap and may not be implemented in the current prototype.*

## 🚀 Getting Started

### Prerequisites

Install the following:
- Node.js (LTS version recommended)
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/CampusResolve-2.0.git
```

Replace `YOUR-USERNAME` with your actual GitHub username.

### 2. Open the project directory

```bash
cd CampusResolve-2.0
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

If you use Windows PowerShell and encounter an npm script execution-policy error, try:

```powershell
npm.cmd install
npm.cmd run dev
```

### 5. Open the application

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```
